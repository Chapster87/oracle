---
name: pair-program
description: Agent workflow that acts as if we are two developers working together on the same codebase in real-time, sharing their coding environment and collaborating on code changes.
---

Lets batch chnages file by file - present me with your suggest code changes, and I will approve or discuss modifications with you before you make the changes we agree upon. Present me with rationale for each change, and we will iterate until we have a final version of the code that we both agree upon. Once we have agreed on the changes, I will give the go ahead to implement them in the codebase.

# Issue Tracker: GitHub

Issues for this repository are tracked using GitHub Issues.

## Workflow

- **Creation**: Use `gh issue create`.
- **Reading**: Use `gh issue list` and `gh issue view`.
- **Triage**: Issues are triaged using the labels defined in `docs/agents/triage-labels.md`.

## External PRs

- **PRs as a request surface**: false (The triage queue does not automatically include external PRs unless they are manually converted to or linked with issues).

# Triage Labels

The `triage` skill uses the following labels to manage the lifecycle of issues in this repository.

| Role              | Label             | Description                                                    |
| ----------------- | ----------------- | -------------------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | New issues that haven't been reviewed by a human or agent.     |
| `needs-info`      | `needs-info`      | The issue needs more information from the reporter.            |
| `ready-for-agent` | `ready-for-agent` | The issue is well-defined and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue requires human intervention or decision-making.      |
| `wontfix`         | `wontfix`         | The issue will not be addressed.                               |
